# ADR 0016：圖塊資源查證與規則幾何分開驗收

Date: 2026-11-03。Status: Accepted for scoped research。

依固定來源及本機標頭比對，場景 1 優先查證 SDX001／SMP001 與圖層圖號除 2 的映射，不再將直接索引 MMAP 的 1×1 結果視為建築沒有圖片的證據。候選標頭成功不等於像素解碼或原版行為驗證；容器尾端異常持續保留。

地板／牆體採原創、版本化 primitive 及材質映射，不要求逐 tile 送模型生成服務。圖片尺寸與錨點只表示 2D 呈現，高度欄位只得到畫面位移的來源支持；3D 長寬高與比例須另外定義並標示 Mock／原創。完整來源與限制見 research/tile-resource-mapping.md。
