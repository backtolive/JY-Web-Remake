# ADR 0055：事件 673 的原版專用狀態提交

日期：2026-11-19。狀態：Phase 3／6 限定事件狀態切片；尚未接入 Web 正式原版遊玩。

沿用 [ADR 0054](0054-event-673-scoped-conversion-comparison.md) 的釘選來源轉換結果，新增 `original-event-673-session.mjs`。它保留現有決策事件的可續行對話游標及資質值，並持有 `ALLDEF.GRP` 的稀疏事件槽覆蓋層。決策內的事件 ID 是待提交鏡像；每次操作驗證它與覆蓋層相同。最後一次 `CONTINUE` 在既有決策交易得出資質 75／事件 ID 674 後，於同一個轉接操作產生場景 32 槽 0 欄 2 的新覆蓋層；任一步失敗都不返回新狀態，舊游標、資質及槽位維持原樣。

限定 checkpoint 將內容身分、五份來源 SHA-256、對話續行與事件槽覆蓋層放在同一份 JSON 中。讀回先檢查精確身分，再核對鏡像及原版槽位。完成狀態只允許 `32/0` 一筆覆蓋紀錄及已觀察的欄 2 更新；其他欄位或槽位變更拒絕。測試涵蓋第 12 段對話前存讀、結束後存讀、重複啟動拒絕、後段錯誤效果回滾、來源鎖定及夾帶欄位拒絕。

此 checkpoint **不是 DOS 存檔，也不是完整 Web 遊戲存檔**。資質目前仍由限定決策狀態承載，尚未與完整人物資料、隊伍、道具、戰鬥及地圖狀態整合。opcode 3 其他欄位、opcode 34 邊界與自然劇情可達性維持未驗；只有這條已觀察前置值 `72／673` 的效果可提交。
