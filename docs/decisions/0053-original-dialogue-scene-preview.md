# ADR 0053：原版純對話場景採事件層逐格解析

日期：2026-11-19。狀態：Phase 3／7 局部唯讀預覽。

既有河洛客棧預覽曾手寫場景 1 槽 2／3／4 對應事件 668／670。現在 `prepare-mvp.mjs` 由原始場景事件層取得格位的槽 ID，再經 `ALLDEF.GRP` 表的欄 2 取得事件 ID；只把 `readDialogueOnlyEvent` 能完整解析且含對話、單格錨點的事件收入同一種本機內容包。不能完整解析的事件保留排除原因，沒有跳過其指令後繼續執行。選定欄 2 是本預覽的互動欄位，尚不推定欄 3／4 的觸發時機。

產生器沿用原本本機預覽包和 Web 匯入方式，新增 `--scene <id>`。場景採不同命名空間，存檔不與河洛客棧預覽共用同一鍵；產物記錄原始檔名、SHA-256、事件槽欄位與 byte 偏移。原始素材只寫到 ignored `assets/generated/mvp`，不納入網站打包。

本機原版資料掃描：84 個場景中，39 個場景至少有一個可解析的純對話事件格。黑木崖（場景 26）產生 35 個事件互動格，對應 6 支純對話腳本與 3 個對話資源；這些格位經現有移動、碰撞、互動及對話存讀檢查。Chromium 以生成包驗證匯入、首格對話、存檔、重整及讀回。此計數不代表 35 名人物，也不證明原版觸發規則或劇情語意；完整效果事件、動態事件槽寫入、切圖與正式原版存檔仍待接入。
