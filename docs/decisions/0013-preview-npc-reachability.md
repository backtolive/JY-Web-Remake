# ADR 0013：原版預覽新增 NPC 必須通過入口可達性檢查

Date: 2026-11-02。Status: Accepted；事件 670 擴充因碰撞模型阻礙而停止。

事件目錄只證明格式支援，不證明 NPC 可從入口走到。場景 1 的槽 3／4 各有可站立鄰格，但在現有保守碰撞模型下均不在預覽入口的連通區；不得只以鄰格存在就開放。

準備工具新增門檻：以核心 MOVE 命令從入口搜尋四方向路徑，逐 NPC 檢查可達、角色格阻擋、正確事件、對話存讀續行，以及旗標／行囊不變。候選未通過時不輸出新包。既有預覽保持場景 1／槽 2／事件 668；`--candidate` 才嘗試包含槽 3／4，且仍必須通過同一門檻。

不移除牆壁、不略過其他事件阻擋、不改入口來掩蓋失敗。後續需查固定來源的通行判定、事件格阻擋與地圖分區；若需要切圖或動態事件才能到達，應另按來源證據實作。這不是 DOS 原版不可達的結論。
