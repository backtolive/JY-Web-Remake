# ADR 0005：通用武俠 RPG 引擎與版本化內容平台

Date: 2026-11-02。Status: Accepted（使用者明確要求的架構方向）；實作尚未開始。

## 決策與目的

核心產品採「通用武俠 RPG 引擎＋金庸群俠傳內容包」，使新增人物、地圖、武功、劇情與結局透過內容與規則介面完成，並可在相同引擎中建立原創 RPG。原版忠實度仍以原始資料、可追溯規則與差異測試驗證。

引擎提供通用狀態與命令、受控事件／對話 Runtime、Rule Engine、純條件求值、內容 registry 與相容性服務。金庸轉接層處理 DOS 結構、原始 ID、provenance 及已確認指令；不把目前有差異的 Pascal opcode 表當成通用腳本契約。遊戲特定公式與結局由版本化規則集及內容包提供。

Game Content Package 具有 manifest、命名空間、穩定引用、版本、相依、雜湊與授權。JSON Schema 處理結構，額外驗證器處理引用、依賴與衝突；編輯器、CLI 與遊戲共用契約及 Runtime。確切欄位、Schema dialect、封裝容器及腳本語法尚待專門 ADR 與實作驗證，本次不預先宣稱格式定稿。

MOD 在滿足相依關係後按確定順序套用；衝突明確拒絕或使用已保存的明確解決方案，不靜默覆寫。原版基底、原創、MOD patch 與存檔各自隔離。通用資料包不授予任意宿主程式碼執行權限，腳本需有執行預算、追蹤與可序列化狀態。

## 存檔契約

從第一版記錄引擎／存檔／Runtime 版本，基礎包、規則集及已解析 MOD 的精確 ID／版本／雜湊、載入順序、設定與組合指紋，以及命名空間化狀態及腳本續行點。寬鬆版本範圍不足以恢復內容環境。

載入先檢查內容組合；缺包、版本／雜湊／順序／設定改變不得直接丟棄狀態或繼續載入。不相容時保留存檔並列出差異；明確支援的遷移在備份副本上驗證後完成，失敗不覆寫。移除 MOD 不保證可遷移。

## 執行順序與驗證

MASTER_PLAN v1.1 保留原有 Phase 0–12 識別碼，新增 Phase 13。Phase 6 先完成內容格式／驗證／Runtime／規則／最小 MOD resolver／存檔相容性；首個 MVP 後交付 Phase 13 的完整平台、視覺編輯器及匯入匯出工作流。

驗收要求同一引擎載入金庸內容包及獨立 Mock 原創包；不修改核心即可新增各類內容。測試涵蓋確定載入、錯誤引用、依賴循環、衝突、多 MOD 狀態、固定 seed 劇情重播、腳本預算、編輯匯出往返與存檔變更／遷移。

此決策擴充 MASTER_PLAN 的架構目標，保留 ADR 0001–0004 的來源、授權與原版研究限制。現有研究及階段驗收沒有因此自動完成；本輪只修改規劃文件。
