# ADR 0033 — 原版世界座標軸與顯示映射

日期：2026-11-04。狀態：採用於完整世界原圖投影。

使用者指出不是偏移，而是座標軸／方向完全不同；畫面貼圖朝向已可辨識，不應用旋轉按鍵或修改阻擋資料補救。來源jinyong-legend commit 89962d7fc2837c143e176c306d83b4e38dab6e77，src/mainmap.c:505–506的格位投影為screenX=(x-y)*18、screenY=(x+y)*9。因此X+在畫面右下，Y+在左下。此為Community Implementation及本機資料支持的投影證據，非執行原版DOS驗收。

舊實作將原版y直接用為Babylon z，現相機下Y+朝右上；地面逆投影也沿用此方向，但upright原圖保持自身朝向，兩者不是同一基底。保留相機alpha／beta，以原版(x,y)→render(x,0,-y)統一完整世界的圖片放置、玩家／鏡頭目標、地面逆投影、小地圖與輸入。原始格位、檔案索引(y*480+x)*2、通行判定及存檔座標均不改。

CameraView增加可選gridYSign，預設+1維持既有Mock／區域介面；完整世界發布-1。鍵盤與按鈕都先做鏡頭相對方向，再把render Z方向轉回原版Y；不是在核心MOVE或阻擋表中轉45度。地面與立面用projectedImageOffset共用同一來源像素基底，立面的垂直像素比例亦對齊相機俯角，避免兩種投影重新產生差異。

本輪驗收只限起點附近X+、Y+與一格已知阻擋；停止擴大世界連通檢查，未執行原版遊戲或全量瀏覽器回歸。既有通行社群規則、船隻與入口未驗收事項不因本修正而提升為Verified Original。
