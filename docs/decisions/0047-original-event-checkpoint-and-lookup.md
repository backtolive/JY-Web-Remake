# ADR 0047：原版事件查找與事件槽 checkpoint 獨立建置

日期：2026-11-15。狀態：採用於原版內容轉接器局部基礎。

原版場景事件層的單格值可指向 200 個事件槽之一，`-1` 表示該格沒有槽。事件槽本身有三個候選事件 ID 欄 2／3／4；它們的觸發語意尚未全部驗證。因此 `resolveOriginalEventAtCell` 由呼叫端**明確指定欄位**，只從格子解析槽位，再讀當前覆蓋層的該欄。ID `-1` 視為停用，其餘 ID 必須在 KDEF 事件數範圍內。函式不推斷「靠近／使用道具／自動觸發」或場景座標軸。

事件槽可序列化狀態採獨立 `original-event-slots` checkpoint，而不冒充完整遊戲存檔。內容鎖記基底包與規則集的版本／SHA-256、MOD 版本／SHA-256／優先權／精確順序、設定及八個原版來源檔 SHA-256；讀回時全部比對，狀態必須和當前 ALLDEF 表雜湊一致。Web 本機儲存使用獨立 key 並保留前一份備份；失敗時舊主檔維持原狀。

此 checkpoint **只保存事件槽覆蓋層**。玩家位置、背包、人物／隊伍、戰鬥、任務與腳本續行點尚未進入同一存檔契約；因此 UI 不應顯示它為可恢復完整進度的存檔。後續完整原版遊戲狀態需升級 Schema，並以備份／相容性預檢遷移，不能只載入事件槽卻丟棄其他狀態。
