# ADR 0052：統一 Mock 遊玩與受控事件工作階段

日期：2026-11-19。狀態：Phase 6／7 局部實作，僅適用目前的 Mock 內容。

## 決策

- v4 存檔同時保存 v0.1 `GameState` 與受控事件續行。玩家位置只存在 `game.mapId/x/y`；受控事件轉場成功時更新該位置。事件續行另存游標、等待命令、決策狀態及亂數狀態，不另存位置。
- `mode` 限制世界命令和受控事件命令互斥；受控事件結束後返回世界模式，世界地圖沿用事件切換後的位置。存讀會核對主內容包精確身分、設定及受控內容和宿主資源身分。
- Web 使用獨立 `jy.web.session.v4` 鍵與上一份備份。v1 存檔須由使用者明確選擇匯入，先以原有驗證器預檢，再寫 v4，原 v1 鍵保持不變。v3 受控事件存檔保持獨立，不隱式遷移。
- Web 重整後可從一般存檔面板載入 v4；等待中的受控事件需回到 Mock 測試入口續行。原版預覽包和本機地圖預覽仍使用既有 v1 遊玩存檔。

## 證據與界線

`tests/unit/unified-session.test.mjs` 覆蓋單一位置、獎勵、切圖、等待點存讀、內容不符／污染資料拒絕、v1 遷移與儲存失敗保留舊值。`tests/e2e/controlled-demo.spec.ts` 覆蓋頁面重整、等待戰鬥結果、切圖、返回世界及一般存檔讀回。這些都是 Mock 場景測試，不能推定原版戰鬥、事件槽、人物／道具規則或完整 MOD 狀態已併入。

後續須將原版事件槽 overlay、正式角色與戰鬥狀態、規則集身分、完整 MOD 相容性及遷移納入同一版本化存檔；每項依其來源和可執行證據驗收。
