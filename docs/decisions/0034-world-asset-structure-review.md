# ADR 0034 — 世界圖片、占格與組合候選先行整理

日期：2026-11-04。狀態：採用於本機資產盤點；不修改遊戲資料或自動產生模型。

使用者已回報人工操作正常，並要求先整理958張世界圖片的單格植被、建築／山體、疊加、多圖組合與占位大小。仍保留逐ID獨立政策：原始圖層只作來源用途，不能直接成為外觀或玩法屬性分類。

盤點以三層原始格網及BUILDX／BUILDY引用為證據，依錨點保存每個實例的精確格子遮罩、外框、原圖尺寸／繪圖偏移及SHA256。單張圖片可以對應多格；同一ID也可能有多種實例占格，故不把一個寬深值硬寫成整個資產ID的固定值。圖片像素高不轉為3D高度。

跨錨點的四鄰格接觸只列為相鄰候選，mergeApproved=false；同時提供按原座標疊加的成員圖預覽。相鄰或圖片重疊不能直接證明屬於同一棟房屋或同一山體。候選外框亦不得取代成員占格的聯集遮罩。人工確認前不合併圖片、材質或碰撞。

圖錄使用本機獨立HTML／JSON，無原版圖片進入公開app／dist。語意類別、是否突起及proxyHeight保持Unknown／null；另產生空白決策模板，供後續逐ID／逐實例決定模型與高度。只做圖錄自身的局部驗證，不執行世界通行或全圖連通檢查。
