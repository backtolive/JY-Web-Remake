# ADR 0006：以 FishEdit 表作研究布局候選

2026-11-02，Accepted for research；正式解析器與原版規則採用仍 Pending。

FishEdit 0.72 公開保存來源明確定義指令 15 長度兩單位，與本機 1,018 個事件完全符合；其文件將 50 描述為五物品條件，不能等同 Pascal 的動態擴充版本。詳見 fishedit-opcode-evidence.md。

補充 ADR 0004：繼續不採用 Pascal 表作 DOS 規格；允許以固定版本 FishEdit 表進行唯讀結構稽核。來源仍屬社群實作，保留所有原始 bytes、雜湊與來源行號。指令 50 的啟用設定與文件不一致，不能以結構相容代替語意驗證。

不執行或複製第三方工具程式碼，不直接製作 DOS VM。指令轉接契約必須區分來源版本，未確認的行為不能成為通用引擎預設。下一步核對 50 條件、15 附帶值及可執行的原版測試案例。
