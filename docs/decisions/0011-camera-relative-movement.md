# ADR 0011：鏡頭相對的八方向移動

Date: 2026-11-02。Status: Accepted，修正使用者回報的 3D 畫面與鍵盤方向不一致。

初版把 W／上鍵直接對應地圖 north，鏡頭卻旋轉 45 度，造成畫面方向錯位。保留斜角構圖，以共享 VIEW_CAMERA 的角度將畫面方向轉為地圖步進。核心只接受地圖方向，不依賴 Babylon 或 React。

核心新增四個斜向命令，保留既有四方向語意與存檔位置。斜走必須目標格及兩個側鄰格都可通行，避免穿牆角或繞過 NPC 碰撞。四個畫面主方向在 45 度鏡頭下會映射為地圖斜向；因此同時提供組合鍵及八方向按鈕，仍能移動到另一奇偶性的格子和所有既有四鄰入口。

鍵盤使用 65 ms 組合鍵窗口，短按放開仍走一步，長按每 140 ms 步進；不依賴作業系統 key repeat。視窗失焦、隱藏、對話／載入阻擋或元件卸載時清除輸入，避免黏鍵。WASD、方向鍵與畫面按鈕共用映射；按鈕名稱改為畫面上下左右，避免誤稱地圖北南東西。

相機改為正交斜角，依 canvas 比例調整可視範圍，避免透視在偏離中心時產生額外的畫面方向漂移。碰撞、物品、事件與存檔資料不因鏡頭改變而重寫。

驗證包含八方向預期、Babylon NullEngine 實際相機矩陣投影（中心／偏離中心）、組合鍵／長按／失焦／對話阻擋、NPC／靜態牆角及出口往返。此輪瀏覽器工具回報 browser.user unavailable，故未宣稱修正版已重新通過實際 UI 操作；正式預覽已更新，仍需手動確認操作手感。
