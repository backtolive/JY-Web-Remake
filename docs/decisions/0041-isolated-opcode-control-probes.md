# ADR 0041：以可還原的隔離腳本驗證原版解譯器控制流

2026-11-14。Status: Accepted for Phase 1／2 限定研究。

原始事件若只有一個 opcode 或後續效果不可見，單純觸發和截圖無法證明該指令是否被解譯器讀取。原始事件 464 的 opcode 55 也因多個相鄰更新而無法分離分支。

允許在 **ignored 的 DOSBox-X 隔離遊戲副本** 中，以等長 Synthetic Script 暫時替換一個事件資源，將待測指令後接已確認的道具效果或場景變更；原始內容來源、產品資料與 KDEF 基線不改。每案記錄載體事件 ID、偏移、原段與整檔 SHA-256、測試 word、隔離存檔前值、原版 DOS 執行結果及還原雜湊。測後先在同一 PID 內回標題，再還原隔離第三槽與 KDEF；若無法驗證還原，停止下一案。工具為 `tools/analyzer/patch_isolated_opcode_probe.py`。

此方法只證明**原版 DOS 解譯器對合成輸入的限定行為**，不能宣稱合成腳本是原版劇情、所有參數已驗收或沒有隱藏副作用。opcode 55 的道具輸出差分、0／65 的一字續行因此得到局部證據；55 的比較／跳轉歸因及 `-1` 特例、0 的重畫效果與 65 的其他效果繼續列為未驗。DOSBox-X emulator save/load state 的已知崩潰限制不因本方法解除。後續歸因界線見 [ADR 0042](0042-opcode-55-trace-evidence-boundary.md)。

邊界對照補充：`0` 對 `0` 和 `-1` 對 `-1` 在合成腳本都走不相等分支；原始語料的 28 次 opcode 55 比較值全為 `-1`。不能把一般正數比較結果擴張到原始事件。`-2` 存檔由現有範圍檢查拒絕，沒有放寬驗證器。
