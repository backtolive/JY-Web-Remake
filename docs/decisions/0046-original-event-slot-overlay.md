# ADR 0046：原版事件槽採來源表加可序列化覆蓋層

日期：2026-11-15。狀態：採用於原版內容轉接器基礎。

原始 `ALLDEF.GRP` 是 100 個場景容量、每場景 200 槽、每槽 11 個 little-endian signed 16-bit 欄位；活躍遊戲中的事件會修改這些欄位。若只把初始事件 ID 固定寫進通用 NPC 內容，事件 464 等劇情更新將無法持續，也無法正確存讀檔。

新增 `packages/game-data/src/original-event-slots.ts`：開啟時複製並計算原版表的 SHA-256；存檔候選狀態只保留版本、來源雜湊與被修改的完整 11 欄槽位。讀取時先核對來源雜湊、地址及全部覆蓋紀錄；寫入只接受已解析好的明確欄位和值，原子回傳新狀態，不更動原始表或舊狀態。原版數值 ID 和欄位位置留在內容轉接層，通用引擎不寫入這些 DOS 規則。

此模組**不解釋 opcode 3 的 `-1`／`-2`**，也不宣稱任何事件可執行。指令轉接器仍須依[逐欄證據](../validation/opcode-3-after-55-event464-fields-20261115.md)先解析語意，再提交明確欄位寫入；無法解析的指令需停止事件且不提交部分狀態。完整遊戲存檔尚需把此覆蓋層納入版本化包／規則集及 MOD 相容性驗證。
