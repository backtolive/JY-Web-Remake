# ADR 0019：原版選區地面以明確原創規則呈現

Date: 2026-11-03。Status: Accepted for local ground-only preview。

將場景 1 選區的 21 個地面圖號映射到 1×0.12×1 原創地板 box。尺寸不是原版還原；材質採解碼圖片不透明像素的 RGB 平均色，不把菱形圖片直接貼到正方形，也不宣稱已完成材質／UV。

轉換先核對 RLE manifest 的來源雜湊，對缺失／錯誤地面證據停止；11 個上層資源不生成替代牆，明確輸出 unmapped 診斷。原區域 blocked 原樣保留，預覽提醒空白可能仍阻擋。格子絕對座標、來源偏移、圖片資源／雜湊及區域相對座標均保留。

來源衍生平均色與 ID 同樣僅留本機，不因使用簡單幾何就當作可公開 Mock。公開 CI 使用獨立 Mock 證據測試，實際本機包只作 optional E2E。下一步才覆核上層資源分類與明確材質製作。
