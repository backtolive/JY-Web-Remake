# ADR 0054：事件 673 先做來源鎖定的限定轉換比對

日期：2026-11-19。狀態：Phase 3／6 局部比較；尚未接入原版可玩事件。

先用既有受控決策 Runtime 比對一條有 DOS 前後狀態紀錄的路徑，不把單一觀察當成 opcode 3／34 的通用語意。`tools/extractor/compare-original-event-673.mjs` 僅接受本機 KDEF、TALK、ALLDEF 五檔的釘選 SHA-256 與事件 673 記錄 SHA-256。來源事件在 KDEF byte 100752，長 158 bytes：12 個 `1` 對話各接 `0`，word 60 為 `3(-2,-2,-2,-2,674,-1,-1,-2,-2,-2,-2,-2,-2)`，word 74 為 `34(0,3)`，最後 `0,-1`。轉換產物記錄原始檔名、資源 ID、byte 偏移、解析器版本與雜湊，含原版對話文字的檔案只放 ignored `assets/generated/event-comparisons`。

比較內容把觀察前的資質 72 與場景 32／槽 0／欄 2 的事件 ID 673 放入明確決策欄位。受控 Runtime 逐段暫停／續行 12 段對話，中途存讀，最後在同一個決策交易中得到資質 75 與事件 ID 674；再把事件 ID 投影到既有原版事件槽覆蓋層，檢查其他欄位仍保留。結果與[原版 DOS 事件 673 紀錄](../validation/opcode-34-dos-observation.md)的兩個觀察後狀態一致。來源 byte 或觀察前資質改變時拒絕這條限定比較。

這是**比較用內容和鏡像狀態**，不是原版遊戲狀態的正式提交。opcode 3 的其他 `-2`／`-1` 參數、opcode 34 上下限、`0` 的畫面效果與自然劇情可達性沒有由此確立；原版事件槽和人物資質尚未整合到 Web 正式遊玩與完整存檔。下一步需讓經驗證的變更寫入原版專用 Runtime 狀態，再以同一來源鎖定與前後狀態測試其提交界線。
