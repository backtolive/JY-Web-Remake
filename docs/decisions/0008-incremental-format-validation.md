# ADR 0008：依功能證據推進解析

Date: 2026-11-02。Status: Accepted，依使用者要求先提交／推送既有工作，再推進；取代 AGENTS 舊有全域研究門檻及 ADR 0007 對 Phase 3 的全面限制。

參考引擎作靜態研究，只有明確問題需要時建置。其執行結果也不是 DOS 原版行為證明。授權未確認的原始碼不複製入產品。

先獨立實作已受來源及 bytes 支持的通用 little-endian uint32 IDX 結束偏移／GRP 邊界讀取。資源 ID 從 0 開始、保留空資源與檔案偏移；不附加事件、地圖或圖像語意。對 MMAP 尾端回到 0 的布局回報錯誤，不裁切或自動修補。資源 bytes 仍留在本機。

未知的 15／50、中文控制符號、MMAP、精確版本與來源授權持續列待辦，只阻擋其對應功能。Phase 1／2、Phase 3 均不可因第一個索引模組完成而整體標記通過。下一個解析格式須另立明確適用範圍與測試。
