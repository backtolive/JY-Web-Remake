# ADR 0012：先以全量支援目錄選擇原版事件擴充範圍

Date: 2026-11-02。Status: Accepted，Phase 3／5 局部交付。

正式 Mock MVP 發布後，依 ADR 0008 的逐功能證據方式擴充原版內容。沿用既有 0／1／7／-1 純對話解析器，先全量列出每筆事件的接受或拒絕原因、TALK 引用與目前場景互動欄位的反向引用。不增加 opcode 語意，不將此目錄當成完整事件流程圖或可達性證據。

報告保留來源檔名、事件／對話 ID、檔案偏移、資源及完整輸入 SHA256、解析器版本、研究來源 commit。工具自行實作，不複製參考引擎程式。逐事件格式或文字錯誤只拒絕該事件；容器／場景布局錯誤或程式錯誤中止整次稽核，避免生成貌似完整的目錄。

只索引 ALLDEF 槽欄位 2；自動／物品觸發、指令動態改寫、地圖通行與事件可達性留待後續。空事件獨立分類，不計入可呈現對話。報告不含對話文字或原始 payload，仍僅寫至 Git 忽略的 assets/generated，不加入網站或 CI 原版資料依賴。

下一個原版預覽候選為既有場景 1 的事件 670（槽 3／4）。正式擴充時須分別確認 NPC 位置、可通行鄰格、來源映射、共用對話的呈現及存讀續行；不得因目錄接受便自動開放所有事件格。
