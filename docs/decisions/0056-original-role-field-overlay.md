# ADR 0056：原版人物欄位採來源表與稀疏覆蓋層

日期：2026-11-19。狀態：Phase 3／6 人物欄位局部解析；未接入 Web 正式原版遊玩。

事件 673 的 DOS 採樣前，主角資質候選欄為 72；本機原始 `RANGER.GRP` 的角色 0 同欄為 50。兩者是不同時間點的資料，不應把 72 寫回原始內容，也不應將 50 當作事件 673 採樣前置。`original-role-records.ts` 只解析 `RANGER.IDX` 指向的 320 筆 × 182-byte 角色區段；開啟時複製來源並計算 IDX／GRP SHA-256。明確 offset 的 signed int16 寫入只回傳新的稀疏覆蓋層，不解釋其他角色欄位或 opcode。

限定事件 673 轉換多鎖定 `RANGER.IDX`／`RANGER.GRP`，記錄角色 0 欄位 byte offset 120、來源 byte 956、原始值 50、DOS 採樣前 72 與事件後 75。事件狀態以覆蓋層建立採樣前 72；最後一次 `CONTINUE` 同時提交決策值、人物欄位覆蓋層及場景 32 槽 0 事件 ID。限定 checkpoint 讀回須核對三者一致，且人物覆蓋層只允許角色 0 的這一個欄位有差異；任一步失敗不變更舊狀態。

這不是原版 DOS 存檔匯入，也不表示 72 是新遊戲開場資質。人物其餘欄位名稱／規則、不同資質前置、自然可達性與 Web 場景互動仍待核對。場景 32 沒有能直接投入現有純對話預覽的事件，後續 Web 接入必須明確保存受控事件、人物與事件槽狀態，避免把限定測試前置當作正式遊戲初始值。
