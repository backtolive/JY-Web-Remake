# ADR 0023：用相同模型對照視覺與邏輯碰撞

Date: 2026-11-03。Status: Accepted for Mock validation。

建立完全獨立 Mock 對照包，不改原版通行判定。兩顆石頭使用完全相同的 GLB、assetId、縮放與材質；綠格 (2,1) 不在 blocked，紅格 (3,1) 在 blocked。裝飾物可穿過與阻擋物不可穿過由內容地圖決定，不能從模型有沒有 collider 推導。

預覽包可附有限數量純文字 previewNotes，匯入前驗證並在畫面顯示；離開預覽時清除。此為測試說明，不是新的腳本或碰撞契約。

繼續採整格碰撞與禁止斜走穿角，不加入半格繞行、攀爬、物理剛體或 GLB collider。未將原版任何格子改為可通行；其判定保留獨立證據要求。
