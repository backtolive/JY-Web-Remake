# ADR 0025：第二個來源占位切片先驗證牆與門口配置

Date: 2026-11-03。Status: Accepted for visual preview; original doorway behavior not accepted。

場景1的(20,22)起點8×8區域包含牆片1708、門側紅柱1710／1712及欄杆2858。直接檢視SMP001的854／855／856圖片後才映射成原創厚度／高度的box，不把封閉輪廓自動合併成完整建築。家具、桌上器物與沒有來源證據的屋頂不自動生成。

門口(22,26)為building=0但event slot15。原始事件欄位0=0，依ADR0015社群來源可通行；現有extractMapRegion仍將所有事件格阻擋。本切片保留該保守策略並顯示限制，不把此結果當成原版門不可通行的證據，也不假裝已驗證門口事件／切圖。門的功能驗收留待通行轉接一致化與相關事件研究。

既有RLE exporter增加明確選區參數，另存不同目錄，不覆寫第一個選區。第二個preview使用不同package ID並保存門口event原值／offset、選區及來源hash。只完成牆段、柱、缺口、尺度與遮擋觀察，不標記整棟建築或屋頂驗收通過。
