# ADR 0027：行跡小地圖順時針旋轉135度

後續狀態：固定角度／鏡射已由ADR0028實際相機投影同步取代；本頁保留使用者需求及修正歷史。

Date: 2026-11-03。Status: Accepted，依使用者指定角度。

後續修正：使用者指出單軸反向。保留135度旋轉，增加畫面X軸鏡射（在rotate前對Canvas執行scale(-1,1)，結果為旋轉後水平反轉），補足top-down canvas與Babylon camera投影的手性差異。背景與標記仍共用相同轉換。回歸測試直接比較MiniMap角色點與WebGL角色在上下左右移動後的像素位移，不能只憑角度或無裁切就宣稱方向一致。

MiniMap內的地圖背景、阻擋格、出口、NPC與角色共用Canvas座標轉換，順時針135度。計算旋轉後包圍尺寸，在192×192畫布內保留8px邊距，避免菱形角落被卡片裁切；非正方形地圖同樣依實際長寬縮放。

只修改顯示；不旋轉邏輯座標、方向鍵映射、來源資料或碰撞mask，無障礙座標仍維持真實格位。這是使用者要求的顯示角度，不新增原版軸向或畫面忠實度結論。
