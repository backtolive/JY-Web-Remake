# ADR 0003：保留地圖尾端與編碼證據

2026-11-02，Accepted for research。

實際地圖檔在第 84 個候選區塊之後仍有非零資料；不能以 RANGER 場景紀錄數裁切原始檔或未來轉換輸出。未確認用途的區域需保留來源位置、雜湊及未知標記。

編碼先記為 Big5 家族的抽樣證據，不把 CP950 或 Big5 單一 codec 宣稱為全域已驗證。原始 bytes 必須保留，轉換不可靜默 replacement。

原附事件轉換器依賴 FishEdit 文字輸出且不完整支援指令，暫不作為正式資料管線。待授權與語意驗證後再評估。此決策未授權進入 Phase 3。
