# ADR 0035 — 只轉換building，首個模型2388

日期：2026-11-04。狀態：使用者人工核定轉換範圍；2388第一版生成候選待驗收。

使用者人工檢視後明確指定只有building需要模型轉換；earth／surface保留原圖投影，最後另行決定。第一個模型選building圖號2388（MMAP圖片索引1194），不得擴大成其他ID的自動分類或批次生成。

依本次指定使用既有LAN管線生成，Job bfee967703174d92856307cc5ed4580e succeeded，使用LOD0；原圖SHA為b7d53e6c010a2fb3634edd51a1fb1b7b2c712ea78a693beb358022a98b140b73。服務產物／原圖衍生包只保留本機ignored，不發布。

2388共有93個放置錨點，周圍buildX／buildY指向該錨點的格位排列有10種；這是逐位置的引用資料差異，不等於10種模型大小，也不足以證明原版把圖片縮放。第一版同ID使用同一模型及尺度，原占格、可走判定、原始三層格網均不改。93個位置不是93份模型檔。

ProjectedMap增加可選models綁定，指定layerId與tileValue，未指定者維持原圖；載入驗證模型SHA、來源ID存在與重複綁定。可見2388圖片改為模型容器實例，保留原圖作來源與回退資料；材質／網格共用，離開視野釋放實例，不改核心邏輯。

尺度只作原創第一版校準：以原圖在現相機下的寬高作等比視覺fit，參考(355,225)原3×3引用區的中心定位。這不是原版實際高度，亦不用93種位置的引用差異自動縮放。原圖背面／厚度未知，未擅自把薄生成結果拉厚。

生成品質限制：SPAR3D輸入單張像素圖後產出偏薄山體；原始推論bbox深度也只有約0.112，表示問題已存在於推論，而非LOD減面造成。第一版不是已驗收的完整立體山體，後續應改進厚度／背面／朝向或使用有體積的人工模型，再擴大到其他building。

2388 通行格圖（Phase 8 局部）：用目前世界預覽 blocked 與圖錄錨點疊合 93 張局部圖，來源 SHA 一致。周圍其他阻擋最少的 4 例各只有 1 格指向此山；因此尚無證據確定共同底面或重疊歸屬。產生器 python tools/analyzer/prepare-2388-blocking-review.py 已成功執行。輸出僅在本機 ignored 目錄。

2388 比對使用本機預覽伺服器提供的固定原圖世界包與玩家格座標，世界包保留於 ignored 目錄。

使用者確認的尺寸政策擴至所有building：逐資源ID統計BUILDX/BUILDY錨點引用所界定的格位外框，最多次數對應的寬／深作模型底面，高度由美術決定。318 ID均輸出到本機 ignored JSON；3 ID並列保留多候選，1 ID無引用缺少底面依據。2388的最常見外框為3×3（78/93，包含稀疏遮罩外框）。這些是底面創作基準，不聲稱是每個引用格均阻擋。
