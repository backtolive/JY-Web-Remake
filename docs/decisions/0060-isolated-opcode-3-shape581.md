# ADR 0060：事件 581 參數形狀的單指令效果

日期：2026-11-19。狀態：Phase 1／2 原版行為證據，Phase 3 尚未開放同形事件通用執行。

沿用 [ADR 0059](0059-event-581-slot-segment-comparison.md) 的來源鎖定參數，將其置於隔離 DOS 遊戲副本的單一 opcode 3 合成腳本。改變目標槽 2 的欄 3／4 前值，且移除原始事件相鄰的 opcode 14、0、13。原版解譯器實際執行後，場景 32／槽 2 由 `[1,2,-1,123,456,2718,2718,2718,0,30,21]` 變為 `[0,0,-1,-1,-1,-1,-1,-1,0,30,21]`。[完整證據](../validation/opcode-3-shape581-isolated-20261119.md)。

2026-11-20 追加對照將欄 2 前值改為 `789`，同一合成腳本執行後成為 `-1`；因此欄 2 也確認是寫入，不是保留。

決策：可將這組**確切參數值**的欄 0–7 效果記為經原版解譯器隔離驗證，欄 8–10 保持原值。原始事件 581 的完整分支前後一致，但本輪使用合成腳本，故不提升為其自然路徑全程驗證，也不推廣到其他同形事件或任意 opcode 3 參數。先前限定投影仍維持不可執行；後續若接入 Runtime，需來源鎖定並限制確切形狀與前置狀態，另驗證失敗時不提交部分變更。

限定轉接已實作於 `tools/extractor/original-event-581-adapter.mjs`：綁定時重新核對三個來源雜湊、事件記錄、指令位置及 13 個參數；執行時只接受未污染的原始前值，並以不可變 overlay 一次寫入欄 0–7。它仍不是通用 opcode 3 handler，也未接入原版自然劇情工作階段。
