# ADR 0021：多片來源圖像組成單一視覺資產

Date: 2026-11-03。Status: Accepted for two-fragment scoped preview。

一張來源圖像不保證等於一個完整模型。群組規則明確指定 anchor 圖號、成員圖號／相對格位及原創 geometry；目前只支援兩片 building 圖像，需圖片的畫面水平邊界恰好相接且垂直範圍重疊。群組判定為 Inferred，不升為 DOS 物件語意。

組裝保存兩成員來源檔／圖號／索引／格位／偏移／長度／SHA256、圖片錨點、畫面位置及接縫。只輸出一個視覺實例，兩成員標為 consumed；單片映射與群組重疊、重複使用、缺片或接縫不符時停止。只有所有出現位置都被群組覆蓋，才移除該圖號的未映射診斷。

群組不合併／改寫原始地圖或碰撞。模型基底、厚度、高度與背面為原創幾何，不從圖片尺寸自動推導；可有大於一格的視覺覆蓋。選區截斷成員時拒絕，不補造缺片。更通用拼接／任意片數及自動搜尋不在本輪範圍。
