# ADR 0051：受控事件的 Web Mock 宿主與引用驗證

日期：2026-11-19。狀態：Mock Web 切片已接入；正式戰鬥與原版內容未接入。

## 決策

在目前 Web 遊戲顯示區加入獨立的「試玩受控事件 · Mock」入口，不更改既有 v0.1 事件或原版預覽流程。Mock 事件與資源清單明確放在 `tests/fixtures`，打包後仍標示 Mock。遊戲內面板依 v2 事件 Runtime 顯示對話、模擬戰鬥結果、動畫進度、切圖確認、選人與 v3 獨立存讀。切圖回覆後，同一顯示區的 3D 場景、地圖標題與行跡讀取受控狀態的位置；離開測試會回到原有遊戲狀態。

Web 宿主綁定前，`bindControlledEventHost` 使用已解析的 v0.1 地圖與明確的 Mock 資源目錄檢查入口及目的地存在且可通行、戰鬥及動畫 ID 存在、候選角色 ID 存在。保存身分的雜湊涵蓋事件內容、宿主內容包身分、設定和 Mock 資源清單，因此換版本、設定或資源後不能誤讀舊進度。外部回覆仍只能選事件已宣告的結果，不能自行寫狀態或座標。

目前頁面原本已將小地圖與行囊移入遊戲區，但舊的側欄存檔在現行 CSS 中隱藏。於遊戲區增加存檔面板，提供既有存讀、匯入／匯出及備份入口；受控測試的存讀仍使用面板內獨立按鈕，不與 v0.1 存檔混淆。舊 Web MVP E2E 改用現行地圖／行囊／存檔入口，重新驗證既有移動、對話、存檔和 MOD 路徑。

## 限制與下一步

Mock 戰鬥以玩家按鈕模擬勝敗，尚無戰鬥規則計算；Mock 動畫只是可見的短暫效果，尚無正式動畫素材；切圖使用既有 Mock 地圖，選人使用獨立 Mock 角色目錄。這些資源目前不是完整 Game Content Package v2、MOD 或正式原版內容。受控狀態和 v0.1 遊戲狀態仍是兩份隔離的存檔，不能宣稱完整遊戲狀態已合併。

下一步應建立正式宿主的資源／規則介面與完整存檔，逐項接入已核對的原版事件效果；原版 opcode 未證實者繼續拒絕受影響事件。
