# ADR 0045：原版事件欄位更新逐欄取證

日期：2026-11-15。狀態：採用於原版內容轉接器研究。

原版 opcode 3 的 13 個參數不可整組直接搬入通用引擎，因為 `-1`、`-2` 在不同位置可能有不同意義。以原始事件 464 的限定對照為基礎，確認其後續 `3(-2,2,-2,-2,862,-1,-1,-2,-2,-2,-2,-2,-2)` 所在路徑把槽 2 的欄 2／3／4 分別寫成 `862／-1／-1`；另一組改前值顯示欄 5／6 在此路徑保留。原版證據見 [差分紀錄](../validation/opcode-3-after-55-event464-fields-20261115.md)。

全量中間資料只附條件式、不可執行的 `originalDosEventUpdate` 註記，保留原始 args、偏移及 FishEdit 候選結構。事件 303 證明先前 opcode 55 的檢查槽和後續 opcode 3 的更新槽可不同，轉接器須分別讀取。`-2` 的其他欄位效果、不同目標場景與事件的覆蓋規則，未有對照前保持未驗證；對其執行不得默默提交局部狀態。這不宣稱 Phase 3／6 或完整原版劇情可執行。
