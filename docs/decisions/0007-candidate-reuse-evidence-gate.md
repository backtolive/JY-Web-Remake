# ADR 0007：候選程式碼採用前的證據範圍

Date: 2026-11-02。Status: Accepted for research boundaries；不是最終引擎採用決策。

## 背景

Phase 2 固定的 A／B 候選均有主程式使用聲明，但另含來自其他作者或上游的檔案；尚未完成外部依賴與素材條款盤點，也未成功編譯。逐檔聲明掃描不能證明整個專案可直接移植。

## 決定

保留兩者作隔離研究來源，產品不複製候選程式碼。採用評估分為逐檔聲明／上游鏈、實際建置依賴組態，以及指定 DOS 版本的行為驗證，各自記錄完成狀態。工具只產生雜湊與行號，不輸出第三方原始碼。

39 個 src C／C++ 檔案的聲明盤點已可重現；Lua、其他目錄、外部依賴與所有素材仍未結案。A list.h 上游鏈與 B ParticleSystem 通知線索保持待審，個別檔案的 MIT／ZLIB／Unlicense 標頭不擴張為整個候選的條款。

## 後果與驗收

下一步先補齊按組態列出的依賴與上游通知，再決定研究建置所需工具鏈。最終引擎採用 ADR、完整授權審查及 Phase 2 驗收仍開放；此 ADR 不授權提前進入 Phase 3／6。依據見 research/license-review.md 與 validation/engine-build.md。
