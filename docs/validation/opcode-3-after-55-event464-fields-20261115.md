日期：2026-11-15。Phase 1／2 原版行為驗證，Phase 3 限定轉換註記。證據分級：以下單次執行為 **Verified Original**；其餘同形原始事件僅為 bytes 推論。

來源是隔離的 DOSBox-X 2026.10.01 `session-002` 遊戲副本，`KDEF.GRP` SHA-256 `135c5e097a7fe561ee931046e1bebf55de9b469678e3d111d8e9f2c6bb600e06`，`KDEF.IDX` SHA-256 `bf02eccf1dab01fd0ae033cdf807f56b978a71a6c2ab9be05e366239b485104b`。原始事件 464 位於 KDEF byte 71352，SHA-256 `0a23ad50eb196bf088274a3187b6cca485bf08646fdda1e658439c688f69eff4`；word 28 是 `55(2,-1,14,0)`，word 33 是 `3(-2,2,-2,-2,862,-1,-1,-2,-2,-2,-2,-2,-2)`。

只複製來源槽 1 到隔離槽 3，將場景 32 槽 0 的事件 ID 指向未修改的 464，並只對待辨欄位做對照：場景 32 槽 2 的 11 欄中，欄位 3／4 原值 `-1／-1` 改為 `123／456`。其他入場座標與解鎖修改均列在 ignored `assets/generated/dosbox-x/op3-after-op55-event464-fields-20261115/manifest.json`；這些是 **Synthetic State**，不是原版劇情進度。

沿用唯一 DOSBox-X PID 7508、遊戲 HWND `0x38085A`。開始前精確遊戲畫格 `z_1234.raw1.png` 為標題頁，`BPLIST` 空。已知鍵序載入第三槽並入場，唯讀掃描場景 32 槽 0 得 `[1,0,464,-1,-1,7448,7490,7448,20,31,25]`。同一程序同一 host 位址 `0x22e964506fc` 的槽 2：

|---|---|
| `Left`、`Enter` 前 | `[1,2,-1,123,456,2718,2718,2718,0,30,21]` |
| 原始事件 464 執行後 | `[1,2,862,-1,-1,2718,2718,2718,0,30,21]` |

這條 `55 → 3` 原版路徑將事件 ID 欄 2 改為 `862`，並將欄 3／4 的 `-1` **寫入**，不能把參數 `-1` 當作「保留」。欄位更新吻合後續 opcode 3 參數；本次沒有在兩指令之間停機取快照，故不單獨排除 55 helper 的隱藏副作用。此前四次 opcode 55 游標 trace 見 [原始事件 464 trace](opcode-55-original-event464-trace-20261114.md)。

第二次可還原對照在同一 PID、同一原始事件，將槽 2 的圖像欄 5／6／7 設為 `3000／3002／3004`；manifest 在 ignored `assets/generated/dosbox-x/op3-after-op55-event464-minus2-20261115/manifest.json`。場景載入後、互動前，唯讀活躍記憶體已是 `[1,2,-1,-1,-1,3000,3002,3002,0,30,21]`：欄 7 在觸發事件前已由存檔值 `3004` 變成 `3002`。觸發後為 `[1,2,862,-1,-1,3000,3002,3002,0,30,21]`。所以此路徑中的 `-2` 圖像欄 5、6 保留了對照前值；欄 7 只證明事件前後活躍值未變，不能把載入時的 3004→3002 歸給 opcode 3。欄 0／1／8～10 與其他 `-2` 變體仍未做改前值對照。
