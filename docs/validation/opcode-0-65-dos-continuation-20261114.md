# 原版 DOS 解譯器的 opcode 0／65 續行與畫面對照

2026-11-14。Phase 1／2；Status: **兩者的一字長度與續行局部確認；完整顯示／隱藏效果未確認**。原始事件 0 僅有 `0,-1`，[上次獨立事件測試](opcode-0-standalone-bounded-20261113.md)沒有可辨認的持久效果；原始事件 939 僅有 `65,-1`，[上次限定採樣](opcode-13-44-65-bounded-20261113.md)也沒有可見效果。這些原始事件缺少後續指令，單看它們不能證明解譯器如何續行。

本輪保留原始 KDEF，僅在 ignored `session-002/game` 隔離副本中，將固定長度的事件 1017 暫時換成 Synthetic Script：分別為 `0,2(57,1),7` 與 `65,2(57,1),7`，餘下 word 填終止值。兩案均由同一 DOSBox-X PID 7508 讀取隔離第三槽，唯讀確認執行中場景 32 槽 0 指向事件 1017；互動後活躍背包都從無 ID 57 變為 ID 57 ×1。這支持**原版解譯器在此兩案各讀過一個 word 並繼續執行後面的給道具指令**。對照腳本、原始事件區段、整檔 KDEF 的前後 SHA-256 都記於 ignored manifest；測試結束已還原原始 KDEF SHA-256 `135c5e097a7fe561ee931046e1bebf55de9b469678e3d111d8e9f2c6bb600e06`。

為分離 opcode 0 的穩定畫面效果，另在隔離副本以等長的事件 464 作 Synthetic Script：兩組都先用 `3` 停用目前事件及其圖像、後接已知事件結束；其中一組中間多一個 `0`。兩案原版執行中槽 0 均從 464 變成禁用 `-1`，事後遊戲專用畫格 `z_1211.raw1.png`（無 `0`）與 `z_1212.raw1.png`（有 `0`）解壓後的 640×400 索引像素**完全相同**。這說明此處的穩定場景更新不需要 `0` 才會出現；它不能排除 `0` 有瞬間重畫、清除前景或改變內部刷新旗標。兩檔 PNG 容器雜湊不同，但像素資料相同，不能只用容器雜湊判定畫面差異。

因此，`0` 的前景重畫語意與 `65` 是否完全無其他副作用仍屬 Unknown。合成腳本只驗證 DOS 解譯器在限定路徑的控制流，**不屬於原始事件 1017／464 的遊戲劇情證據**。所有合成 KDEF 和存檔測後已依 manifest 還原，DOSBox-X PID 7508／遊戲 HWND `0x38085A` 保持開啟。
