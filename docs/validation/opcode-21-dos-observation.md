# 原版 DOS 事件 950 的角色 1 離隊

2026-11-12。Phase 1／2，局部原版執行證據。原始事件 950 位於 KDEF byte 113454，長 42 bytes，SHA-256 `a901c75f40e733d0252ea20c0c40e42ae7bc139e32675f862724d6a29e6435eb`；候選切分為 `1(2707,0,1),21(1),3(0,0,1,1,951,-1,-1,5166,5166,5166,0,-2,-2),-1`。KDEF 未修改。

隔離 `session-002` 第三槽以 Synthetic State 將隊伍槽 1 設為角色 1「胡斐」，場景 32 槽 0 指向事件 950。DOSBox-X 2026.10.01 進場後，唯讀搜尋到兩份 `[0,1,-1,-1,-1,-1]`：載入存檔副本（此 PID host `0x28a4301388c`）及後接世界座標欄的執行中隊伍（`0x28a43013bb8`）。場景事件槽為 950。

觸發後 `z_465.raw1.png` 有原始下方對話；送 Enter 後 `z_466.raw1.png` 覆蓋層消失。相同執行中隊伍地址變為 `[0,-1,-1,-1,-1,-1]`，載入存檔副本仍為 `[0,1,-1,-1,-1,-1]`。事件 950 的候選指令中，對話後唯一修改隊伍的指令是 `21(1)`；後續 opcode 3 的候選效果是改事件內容。因此本案例支持 opcode 21 將指定角色 1 從執行中隊伍移除。

先前 `synthetic-op21-event950-role1-20261112` 與 `synthetic-op21-event950-slottrace-20261112` 僅讀取載入存檔副本，曾誤報「隊伍未變」；該負面推論已撤回。有效案例的所有改動、byte offset、原值、SHA-256 與備份見 ignored 的 `synthetic-op21-event950-runtime-team-20261112/manifest.json`。關閉唯一精確 DOSBox-X 程序後第三槽六檔恢復基線雜湊。

尚未驗證其他角色 ID、角色不在隊時行為、隊伍壓縮規則、額外攜帶物品或自然流程可達性。本案的 host 地址不是固定 guest offset。
