# 原版 DOS 指令 38 的場景貼圖替換

2026-11-12。Phase 1／2，局部原版執行證據。原始事件 434 位於 KDEF byte 66464，SHA-256 `ebc33f2f67b16cd9e2311ae3aa4d0f4b9394f3e2c156893aec8b531c8e4a225c`；第一條候選指令為 `38(-2,0,990,994)`，後面才有兩條 opcode 3。KDEF 未修改。

DOSBox-X 2026.10.01 隔離 `session-002` 將場景 32／槽 0 指向事件 434，並在 `S3.GRP` 場景 32 第 0 層列優先 `(12,22)` 設合成前置值 990；其餘原版圖層資料不動。六個第三槽檔的原值、改值、SHA-256 與備份見 ignored 的 `synthetic-op38-event434-20261112/manifest.json`。入場後以唯讀執行中記憶體定位完整圖層，在同一 PID 14572、同一 host 位址 `0x15f7da1c800` 比對。該位址只在此程序有效。

| 時點 | 層內 ID 990 格數 | 層內 ID 994 格數 | `(12,22)` 列優先值 |
|---|---:|---:|---:|
| 事件前，`z_303.raw1.png` 室內 | 1 | 0 | 990 |
| 第一次 Enter，`z_304.raw1.png` 只見 NPC 動作 | 1 | 0 | 990 |
| 第二次 Enter，`z_305.raw1.png` | 0 | 1 | 994 |

這支持 `38(-2,0,990,994)` 在本次場景 32 第 0 層將現有圖號 990 改為 994。後面的 opcode 3 修改事件欄位，不能用來解釋此層格值變化。只放入一格 990，因此「替換所有相符格」及其他場景／層、無相符值、視覺刷新仍未驗證；`-2` 解析為當前場景的解釋僅由本案例支持。場景／事件映射與原圖層單格值為 Synthetic State。測後關閉唯一遊戲程序，依 manifest 還原第三槽六檔 SHA-256。
