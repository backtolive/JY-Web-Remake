# 第一個可操作 Web MVP

## 最新控制修正

使用者回報初版 3D 與鍵盤方向不一致後，已改為「畫面相對」八方向控制。↑／W 往畫面上、↓／S 往畫面下、←／A 往畫面左、→／D 往畫面右；兩個方向鍵可組合，例如 W＋D 是畫面右上。也可使用八方向按鈕。按鈕不再標示為地圖北／南／東／西。

維持斜角構圖但採正交投影；核心斜走檢查目標與兩側格，避免穿牆角。65 ms 組合鍵窗口、短按一步、140 ms 長按步進，失焦或對話阻擋時停下。見 ADR 0011。

新增 4 項測試（總 Node 19 項）：八方向映射、Babylon 實際相機矩陣投影在中心及偏離中心都對應正確、組合鍵／長按／停止，以及牆角／NPC／出口可達性。本輪瀏覽器 API 無法使用，因此以實際相機數學投影與核心整合驗證；未冒稱修正版經實際 UI 重測。下列初版瀏覽器紀錄保留作歷史證據，其中「s 切圖」已改為畫面右上（W＋D 或 ↗）對應既有出口。

## 執行與打包

```powershell
pnpm install --frozen-lockfile
pnpm run dev
```

開發網址為 http://127.0.0.1:5173/。建置及檢查：

```powershell
pnpm run build
node tools/validator/check-web-build.mjs
pnpm run preview
```

正式打包預覽為 http://127.0.0.1:4173/；可發布檔案全部位於 `apps/web/dist`。頂層 dist 是核心 TS 輸出，不能作為網站發布目錄。使用 Node 24、pnpm 11.25.0，pnpm 只允許 esbuild 的必要安裝腳本。

## 功能與隔離

React UI 只派送既有核心命令，Babylon.js 負責固定斜角 3D 占位美術；碰撞、事件、狀態與存檔未在 UI 另寫一份。方向鍵／WASD 移動，E／Enter／空白開啟鄰格對話或繼續；也提供按鈕。選項由點選按鈕執行，對話期間停用移動。

預設為獨立 Mock 原創包：引路人對話／選項／一次性物品、練功房與庭院往返。內容設定可開啟問候 MOD；切換內容從入口開始，原先存檔按內容組合分開保存。

使用 `pnpm run mvp:prepare` 產生的 `.local.json` 原版包，可從「內容與測試設定 → 匯入本機原版預覽包」選取。只在瀏覽器以 File API 讀取；網站沒有上傳端點。原版切片仍只支持已記錄的河洛客棧對話；占位視覺顯示通行格、障礙與人物，不宣稱已重建原版圖像或建築。其餘六層呈現 metadata 尚未完整用於畫面生成。

Vite 建置插件會拒絕匯入 original、references、assets/generated 的檔案；正式輸出只有 Mock 與程式。原版／參考程式碼／玩家存檔不隨網站打包。若 WebGL 無法初始化，顯示平面備援與提示，核心按鈕仍可測試；不能把備援稱為 3D 通過。

## 存檔

存檔使用瀏覽器 localStorage，內容包 ID 組合分槽；Schema／Runtime／版本／hash／順序／設定仍由核心預檢。儲存前先驗證新內容，舊 main slot 先存 backup，然後寫新 main。Quota／備份錯誤不移除舊 main；提供讀取、備份恢復及 JSON 匯出／匯入。匯入只變更目前遊戲狀態，不自動覆寫本機存檔。

存檔與網站 origin 綁定：5173 開發版、4173 預覽版及未來正式網域各自分開。換網址或裝置前須匯出 JSON；清除瀏覽器資料可能移除存檔。沒有帳號或雲端同步。

## 本輪實際驗證

| 案例 | 結果 |
|---|---|
| 正式版畫面與 renderer 狀態 | Babylon 3D 可見、data-renderer=ready；不是平面 fallback |
| 方向鍵碰撞 | 起點向北被阻擋、位置保持 (1,1) |
| NPC／對話／選項／背包 | 互動後可選領取，背包增加練習銅錢 ×1 |
| 對話中保存、重新整理、讀回 | 對話與 cursor 恢復，繼續至選項；正式打包版亦通過 |
| 鍵盤及切圖 | s 向南進入庭院，再 s 返回練功房 |
| MOD | 開啟後出現替換的問候對話 |
| 不相容存檔匯入 | 在 MOD 對話期間匯入無 MOD 的 Mock 存檔，被拒絕；原對話未改變 |
| 本機原版切片 | 透過檔案選擇器匯入，顯示河洛客棧並讀取指定唯讀對話 |
| 響應式 | 390 與 1280 視窗測試，實際內容寬 375／1265（含捲軸差）；無水平溢出，桌面雙欄成立；測後恢復預設 |
| 瀏覽器錯誤 | 本輪抓取 error／warn 為空 |
| 正式輸出 | HTTP 200，65 項目（含 assets 目錄），入口相對資產 4 個、無商業資源檔案 |

瀏覽器人工自動操作記錄與 Node 測試分開；並非已交付可獨立執行的 E2E 測試套件。新增 2 項 Mock storage 測試涵蓋分槽／暫停恢復／備份、無效 state、備份與 main quota 錯誤後保留舊資料；Node 合計 15 項，Python 4 項。

本機原創畫面證據保存在 `assets/generated/web-check/mvp-browser.png`，受 Git 忽略，沒有原版對話內容。建置有單一 Babylon chunk 大於 500 kB 的提示；renderer 已動態載入，尚未作完整效能優化。

尚待：正式託管部署、真實手機硬體／觸控長按測試、瀏覽器儲存配額實機、原版圖像／音效、完整劇情與戰鬥。UI 匯出按鈕與格式已有實作，實際檔案下載回匯的完整瀏覽器路徑尚待獨立驗證；有效／無效存檔恢復由核心及 storage 測試涵蓋。
