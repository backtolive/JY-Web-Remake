# 事件 581 已驗狀態效果轉接 — 2026-11-20

證據範圍：Phase 3／6 限定切片。轉接器鎖定 KDEF／ALLDEF／ALLSIN／RANGER 六個來源雜湊、事件 581 記錄與指令位置；它不是通用 opcode handler。

單人 DOS 採樣前置 `[0,-1,-1,-1,-1,-1]` 完成後，單一不可變交易產生：隊伍 `[0,49,-1,-1,-1,-1]`；場景 32 槽 2 為 `[0,0,-1,-1,-1,-1,-1,-1,0,30,21]`；角色 49 的 offset 34／36／80／82／84／86／88／128 分別成為 `238,238,2,321,321,44,50,15`。本機原始 RANGER 基線恰為 `38,38,1,21,21,14,30,0`，與 DOS 採樣前值一致。

六人 DOS 採樣前置 `[0,1,2,3,4,5]` 只進入 `blocked-full-party`，事件槽、角色與隊伍 overlay 均保持空。其他隊伍排列拒絕。完成狀態若多改角色 49 offset 42、其他 byte、其他角色或事件槽，checkpoint 驗證拒絕；這保留尚未歸因的 `90→92` 差異。

靜態路徑檢查另確認擂鼓山事件鏈 `533→534→536→581`，以及事件 536 word 160 起的 52 words 與事件 581 終止符前 body 逐 byte 相同。這不證明 536 分支可達，也不授權其後場景 28 寫入或轉場效果。

測試涵蓋來源改動、前置污染、角色額外 byte、序列化／恢復、重複執行與滿隊阻擋。完整結果記於同日 `docs/PROGRESS.md`；設計界線見 [ADR 0061](../decisions/0061-event-581-partial-session.md)。
