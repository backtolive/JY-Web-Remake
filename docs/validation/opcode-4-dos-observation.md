# 原版 DOS 事件 16 的指定物品分支

2026-11-13。Phase 1／2 局部原版執行證據。原始事件 16 位於 KDEF byte 1596，SHA-256 `e85d1d7a571d388d0f095b45af3302128419fd36d953cbd9476d27d16c4a083d`；候選序列為 `4(160,1,0)`、`7`、`1(2897,0,1)`、`0`、`-1`。KDEF 未修改。

隔離 `session-002` 第三槽把場景 32 槽 0 指向事件 16，背包加入 ID 160 ×1。讀檔後唯讀確認事件 16 與兩份背包候選紀錄的 ID 160 ×1。原版 ESC 主選單第三項「物品」，背包第 5 格為「唐詩選輯」（ID 160）。選該物品後返回場景，對同一相鄰事件按 Left、Enter，`z_804.raw1.png` 顯示「我一定是瘋了，才會想把這書燒掉！」；該原始事件只在候選 `4(160,1,0)` 的正確路徑後接這段對話。對話關閉後事件 ID 仍為 16。

同一程序、同一事件位置再選背包第 1 格「康培特」（ID 0）作控制；返回場景後同樣按 Left、Enter，`z_811.raw1.png` 沒有對話覆蓋層，事件仍為 16。這支持本案例 opcode 4 依指定物品 ID 160 分支。ID 0 是否屬「使用物品」參數、或只是普通消耗品操作，尚未由 DOS trace 隔離；因此只確認 ID 160 正路與非 ID 160 的無對話對照，不宣稱完整跳轉公式。物品 160 數量仍為 1，沒有把此指令當消耗物品。

所有合成改動、原值與備份／SHA-256 見 ignored `synthetic-op4-event16-useitem160-20261113/manifest.json`。測後精確關閉唯一 DOSBox-X 程序並還原六檔。入場與道具前置是 Synthetic State；自然流程可達性、其他物品與參數未驗。
