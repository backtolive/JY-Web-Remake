# 原始資料匯入

請將合法取得的 DOS 遊戲完整目錄置於 original/dos/，保持原檔唯讀備份。不要只提供 EXE，也不要先改名、轉碼、覆蓋或合併不同版本。此目錄除本文件外全部忽略提交。

需提供：完整遊戲資料、版本／語系／來源說明、是否套用 MOD 或修補，以及可選的測試存檔與 DOSBox-X 設定。尚未取得實際檔案，不能指定已確認的必要檔名。

執行 `pnpm inventory original/dos docs/research/inventory.local.json`。輸出必須位於輸入之外且不能覆寫既存檔。雜湊報告預設不提交，人工檢查檔名與來源資訊後再整理公開摘要。盤點不解析資料、不辨識版本、不宣稱副檔名代表確定格式。
